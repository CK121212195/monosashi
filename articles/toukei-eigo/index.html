漢字の用語が、頭に入ってこない理由

帰無仮説、不偏分散、残差、決定係数。統計の授業や統計検定の勉強を始めると、見慣れない漢字の用語が次々に出てきます。字面から意味を想像しにくく、定義を丸暗記するしかない、と感じた人も多いはずです。

これらの用語の多くは、英語などで生まれた概念に、あとから日本語をあてたものです。だから、もとの英語を知ると「なぜその名前なのか」が見えてきます。名前の理由が分かれば、定義は覚えるものではなく、読めば分かるものに変わります。

もう一つ、実用的な理由もあります。統計ソフトの出力、海外の教科書、論文、オンラインの解説。統計を使う場面の多くは、最初から英語です。統計検定2級でも、統計ソフトの出力を読み取る問題が出ます。英語の用語に慣れておくことは、試験対策としても遠回りではありません。

この記事では、統計検定2級の範囲で特に大事な用語を、英語の意味から読み直します。

ばらつきの言葉：deviation と error

deviation：道から外れる

標準偏差は standard deviation です。deviate は、ラテン語の de（離れて）と via（道）からできた語で、「道から外れる」という意味です。

ここでいう道は、平均です。各データが平均という道からどれだけ外れているか。その外れ具合（偏差）を2乗して平均したものが分散（variance）、その平方根が標準偏差です。variance は vary（変わる・ばらつく）の名詞形なので、こちらもそのまま「ばらつき」です。

error：間違いではなく「ずれ」

標準誤差は standard error。error は日常語では「間違い」ですが、統計では推定した値と本当の値のずれを指します。誰かがミスをしたわけではありません。

統計検定2級で最も取り違えやすいのが、この2つです。

英語日本語何のばらつきか
standard deviation標準偏差データそのもののばらつき
standard error標準誤差標本平均などの推定値のばらつき（標本を取り直すたびに変わる幅）

標本平均の標準誤差は、標準偏差を√n で割った値です。deviation は「データが道から外れる」、error は「推定が真の値からずれる」。何がずれているのかを英語で言い分けられれば、式の√n がどこから来るのかも迷わなくなります。

検定の言葉：null・significant・reject

hypothesis：下に置くもの

仮説は hypothesis。ギリシャ語の hypo（下に）と thesis（置くもの）からできた語で、議論の下に置く前提という意味です。複数形は hypotheses（ハイポセシーズ）です。

null hypothesis：「何もない」という仮説

帰無仮説は null hypothesis。null は「ゼロ・何もない」という意味です。つまり帰無仮説とは、「差はない」「効果はない」という、何も起きていない状態を仮に置く仮説です。この用語は、統計学者フィッシャーが1935年の著書『実験計画法（The Design of Experiments）』で使ったものが広まりました。

日本語の「帰無」も「無に帰する」と読めば同じ意味ですが、英語の null のほうが直感的です。記号は H₀ と書き、英語では「エイチ・ノート」や「エイチ・ゼロ」と読みます。対立仮説は alternative hypothesis（代わりの仮説）で、H₁ と書きます。

significant：「重要」ではなく「示された」

「有意な差」は statistically significant。significant は日常語では「重要な・大きな」という意味で使われますが、もとは signify（示す・意味する）の形容詞です。

統計で significant と言うときは、「偶然だけでは説明しにくい差が、データに示された」という意味です。差が大きいとも、重要だとも言っていません。件数が多ければ、ごく小さな差でも有意になります。この点はその差は偶然か｜p値の読み方と、実務的に意味のある差で、計算例を使って詳しく書いています。

reject と fail to reject

帰無仮説を棄却することは reject the null hypothesis。棄却できなかったときは、英語では fail to reject（棄却に失敗する）と言います。

ここに、とても大事な考え方が表れています。棄却できなかったことは、帰無仮説が正しいと示されたことではありません。証拠が足りなかっただけです。「有意差なし＝差がない」と読んではいけない理由が、英語の言い回しにそのまま入っています。

Type I error と Type II error

第1種の過誤は Type I error、第2種の過誤は Type II error。I と II はローマ数字なので、「タイプ・ワン」「タイプ・ツー」と読みます。

  • Type I error：本当は差がないのに、差があると判断してしまう（正しい帰無仮説を棄却する）
  • Type II error：本当は差があるのに、見逃してしまう（誤った帰無仮説を棄却できない）

差があるときに正しく見つけられる確率を検出力（power）と言い、1 −（第2種の過誤の確率）で表します。

推定の言葉：estimate と confidence

estimate と estimator

推定値は estimate、推定量は estimator です。estimator は「推定に使う計算の決まり（式）」、そこに実際のデータを入れて出てきた数が estimate です。日本語の「推定量」と「推定値」の区別が、英語では語尾の違いとして現れます。

発音にも注意が必要です。estimate は、名詞なら語末が「メット」（/ˈestɪmət/）、動詞の「推定する」なら「メイト」（/ˈestɪmeɪt/）に近い音になります。

confidence interval：何に「信頼」しているのか

信頼区間は confidence interval。interval は「区間」です。

95%信頼区間は、よく「本当の値が95%の確率でこの区間に入る」と説明されますが、これは正確ではありません。本当の値（母数）は1つに決まっていて、確率的に動くのは区間のほうだからです。正しくは、同じ手順で標本を取り、区間を作ることを何度も繰り返すと、そのうち約95%の区間が本当の値を含む、という意味です。confidence（信頼）は、1つの区間ではなく、区間を作る手順に対する信頼です。

degrees of freedom

自由度は degrees of freedom。自由に動ける値の個数です。統計ソフトの出力では df や Df と略され、on 18 degrees of freedom のように書かれます。

回帰の言葉：regression と residual

regression：後戻りする

回帰は regression。regress は「後戻りする」という意味です。

なぜ「後戻り」なのか。19世紀の終わりにゴルトンが親子の身長を調べたところ、とても背の高い親の子は、親ほどは背が高くならない傾向がありました。子の身長が平均のほうへ「戻る」。ゴルトンはこれを regression towards mediocrity（平凡への回帰）と呼び、ここから regression という名前が、直線を当てはめる方法そのものの名前として残りました。

今では、名前の由来とは関係なく、ある変数で別の変数を説明する式を求める方法全般を回帰と呼んでいます。

residual：残りもの

残差は residual。「残りもの」という意味です。実際の値から、回帰式で当てはめた値（fitted value）を引いた残りが残差です。式で説明しきれずに残った部分と読めば、名前のとおりです。

最小二乗法（least squares）は、この残差の2乗（squares）の合計を最も小さく（least）する方法。英語をそのまま訳すと、方法の中身が説明になっています。

intercept・slope・coefficient

  • intercept：切片。直線が y 軸を「横切る（さえぎる）」点です。名詞は前を強く、イ́ンターセプトと読みます
  • slope：傾き。日常語では「坂」です
  • coefficient：係数。回帰式で変数にかかる数で、切片や傾きをまとめてこう呼びます

統計ソフトの出力を、英語のまま読む

ここまでの単語がそろうと、統計ソフトの出力がそのまま読めるようになります。次は、20人の「1週間の勉強時間（hours）」と「模試の得点（score）」の架空のデータで単回帰分析をした結果です。統計ソフトRの summary(lm(score ~ hours)) と同じ形式にそろえて示しています。

出力の数字は、互いにつながっています。t 値は推定値を標準誤差で割ったもの、F 統計量は（単回帰なら）t 値の2乗、決定係数は（単回帰なら）相関係数の2乗です。1つの数字の意味が英語で分かれば、残りは計算で確かめられます。

読み違えやすいところ：この結果は「勉強時間を1時間増やせば、得点が2.4点上がる」という意味ではありません。データは観察しただけのもので、勉強時間の長い人は、ほかの面でも得点につながる条件を持っているかもしれないからです。Correlation does not imply causation（相関は因果を意味しない）。英語でも日本語でも、統計の授業で繰り返し出てくる一文です。

用語は英語とセットで、声に出して覚える

統計の用語を覚えるときは、日本語と英語をセットにして、1つの語につき次の3つを確かめるのがおすすめです。

  1. 英語の意味：residual なら「残りもの」。名前の理由がここで分かります
  2. 日本語の用語：残差。英語の意味と結びつけて覚えます
  3. 発音：音で覚えると、英語の講義や動画でも聞き取れるようになります

この記事で取り上げた語を含め、統計検定2級の範囲の用語を英語でまとめた単語一覧を用意しました。すべての語に意味・発音記号・ひとことメモ・音声がついています。
