名詞と数量表現（可算・不可算）

名詞まわり 高校文法

不可算名詞の代表

information, advice, equipment, furniture, baggage / luggage, news, evidence, feedback, research, machinery, merchandise, traffic, homework, knowledge, progress, access など。
数えるときは a piece of advice, two pieces of equipment のように表します。

  • He gave me some useful advice.
    彼は役立つ助言をくれた。× an advice / advices
  • All the equipment has been checked.
    すべての機器が点検済みだ。単数扱い

数量詞の使い分け

可算：many, few（ほとんどない）, a few（少しある）, a number of（多くの）。
不可算：much, little（ほとんどない）, a little（少しある）, an amount of。
両方：a lot of, some, any, plenty of, most。
a number of＋複数名詞＋複数動詞（多くの～）／the number of＋複数名詞＋単数動詞（～の数）。

  • A number of employees have applied.
    多くの従業員が応募した。複数扱い
  • The number of visitors has increased.
    来場者の数が増えた。単数扱い
  • There is little time left.
    残り時間はほとんどない。不可算＋little

each / every / 集合名詞 / 数詞の形容詞化

each / every＋単数名詞＋単数動詞。each of the＋複数名詞 も単数扱い。
people, police, cattle は常に複数扱い。staff, team, family は「まとまり」なら単数、「メンバー」なら複数扱い（米では単数が多い）。
数詞＋名詞で形容詞にするときは単数形：a five-year plan（× five-years）、a ten-minute break。

  • Each employee has a locker.
    各従業員にロッカーがある。
  • The police are investigating the case.
    警察がその事件を捜査している。複数扱い
  • We took a ten-minute break.
    10分間の休憩をとった。× ten-minutes

⚠️ 間違えやすいポイント

  • information / advice / equipment / furniture / news に -s をつけない。
  • a number of（多くの）と the number of（～の数）で動詞の形が違う。
  • a five-year plan の year は単数。

🎯 TOEIC・英検での出方

「a number of と the number of」「each＋単数名詞」「不可算名詞に an / many をつけない」は Part 5 の頻出ポイントです。

演習問題（5問）

Q1 The number of online orders    risen sharply this year.

  1. were
  2. has
  3. are
  4. have
正解と解説を見る

正解：2. has

今年、オンライン注文の数が急増した。

the number of（～の数）は単数扱いなので has。

Q2 A number of customers    complained about the delay.

  1. was
  2. is
  3. has
  4. have
正解と解説を見る

正解：4. have

多くの顧客が遅れについて苦情を言った。

a number of（多くの）＋複数名詞 は複数扱い。

Q3 The technician checked    piece of equipment carefully.

  1. each
  2. all
  3. many
  4. both
正解と解説を見る

正解：1. each

技術者はそれぞれの機器を注意深く点検した。

piece は単数なので each。all / many / both の後は複数形（または不可算名詞）が来ます。

Q4 We received very    feedback on the first draft.

  1. a few
  2. little
  3. few
  4. many
正解と解説を見る

正解：2. little

最初の原稿にはほとんど意見が来なかった。

feedback は不可算名詞なので little（ほとんどない）。few / many / a few は可算名詞用。

Q5 The company announced a    plan to cut emissions.

  1. five-year
  2. five year's
  3. five years
  4. five-years
正解と解説を見る

正解：1. five-year

その会社は排出削減の5か年計画を発表した。

数詞＋名詞をハイフンでつないで形容詞にするときは単数形。
