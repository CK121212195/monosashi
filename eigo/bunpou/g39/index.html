仮定法の発展（if のない仮定法・倒置）

難関大・東大：重要文法の発展 難関大・東大

難関大の英文では、if が出てこない仮定法がよく使われます。助動詞の過去形（would / could / might）に気づき、「どこに仮定が隠れているか」を見抜く練習をします。

📗 先に確認したい基礎：仮定法①（過去・過去完了・混合）、仮定法②（wish・as if・倒置・仮定法現在）

if を使わない仮定法

仮定の意味は、if 節以外にも隠れています。
主語：A wise person would not say such a thing.（賢い人なら…）
副詞句：with / without / but for（～があれば・なければ）、in your position（あなたの立場なら）など
otherwise（さもなければ）、to 不定詞（To hear him speak, you would …：彼が話すのを聞いたら）
would / could / might が出てきたら、「仮定はどこにあるか」を探します。

  • Without your help, I could not have finished the project on time.
    あなたの助けがなければ、私はその計画を期限内に終えられなかっただろう。Without ～＝If it had not been for ～
  • I was very busy; otherwise, I would have joined you.
    とても忙しかった。そうでなければ、ご一緒していたのですが。otherwise＝if I had not been busy
  • A true friend would have told you the truth.
    本当の友人なら、あなたに真実を伝えていただろう。主語に仮定が含まれる

if の省略による倒置と、仮定法未来

if を省略すると、Were S / Had S / Should S が文頭に出ます（書き言葉で頻出）。
Had I known the truth, I would have acted differently.（＝If I had known）
Were it not for ～（～がなければ）、Had it not been for ～（～がなかったら）
Should S ～（万一～なら）：主節は命令文や will も可。If S were to ～：仮に～するとしたら。

  • Had it not been for the Internet, the movement would not have spread so quickly.
    インターネットがなかったら、その運動はあれほど速く広がらなかっただろう。If it had not been for の倒置
  • Should you have any questions, please contact us.
    万一ご質問がありましたら、ご連絡ください。If you should have の倒置
  • If the sun were to disappear, life on Earth would end.
    仮に太陽が消えたとしたら、地球の生命は終わるだろう。were to：仮の想定

仮定法を使った重要表現

It is (high / about) time S＋過去形：もう～してもよいころだ。
I would rather S＋過去形：S に～してほしい（のだが）。
as if / as though：まるで～のように（主節と同時なら過去形、それより前なら過去完了）。
if only：～でさえあれば（強い願望）。
要求・提案の that 節：suggest / insist / demand / recommend / It is essential that S (should)＋原形（仮定法現在）。

  • It is high time we took action on climate change.
    そろそろ気候変動に対して行動を起こすべき時だ。It is time＋過去形
  • The committee recommended that the plan be postponed.
    委員会は、その計画を延期するよう勧告した。be は仮定法現在（should be も可）
  • If only I had listened to my parents.
    両親の言うことを聞いてさえいればよかったのに。過去の事実に反する願望

⚠️ 間違えやすいポイント

  • 混合仮定法：if 節が過去完了でも、主節が現在のことなら would＋原形（If I had studied harder, I would be a doctor now.）。
  • 仮定法現在の that 節では、三人称単数でも動詞は原形（× recommended that the plan is postponed）。
  • 倒置の Had I known を疑問文と読み違えない（文末が疑問符でないことを確認する）。

🎯 入試（難関大・東大）での出方

難関大の和訳問題では、if のない仮定法（without・otherwise・主語に含まれる仮定）を「～なら」「～がなければ」と訳出できるかが問われます。英作文でも、仮定法を正しく使えると表現の幅が広がります。

演習問題（6問）

Q1    the support of their families, many of the athletes would have given up.

  1. Despite
  2. Without
  3. Unless
  4. Except
正解と解説を見る

正解：2. Without

家族の支えがなかったら、選手たちの多くはあきらめていただろう。

主節の would have given up から仮定法過去完了とわかる。名詞句を続けて「～がなければ」を表すのは Without（＝If it had not been for）。Unless は接続詞なので後ろに S V が必要。

Q2    I known about the traffic jam, I would have taken the train.

  1. Had
  2. Have
  3. If
  4. Did
正解と解説を見る

正解：1. Had

交通渋滞のことを知っていたら、電車に乗っていたのに。

If I had known の if を省略した倒置 Had I known。If を使うなら If I had known の形が必要。

Q3 It is about time the government    the problem seriously.

  1. has taken
  2. will take
  3. takes
  4. took
正解と解説を見る

正解：4. took

そろそろ政府がその問題に真剣に取り組んでもよいころだ。

It is (about / high) time S＋過去形（もう～してもよいころだ）。

Q4 The doctor insisted that he    smoking immediately.

  1. would stop
  2. stop
  3. stopped
  4. stops
正解と解説を見る

正解：2. stop

医師は、彼がすぐにたばこをやめるよう強く求めた。

insist が「強く要求する」の意味のとき、that 節は (should)＋原形。主語が三人称単数でも stop のまま。

Q5 If she had taken the job in Tokyo, she    a very different life now.

  1. would have lived
  2. had lived
  3. would be living
  4. will live
正解と解説を見る

正解：3. would be living

もし東京でその仕事に就いていたら、彼女は今ごろまったく違う生活を送っているだろう。

if 節は過去の事実に反する仮定（過去完了）、主節は now があるので現在の事実に反する仮定（would＋原形）。混合仮定法。

英文の意味として最も適切なものを選ぶ

Q6 A little more care would have prevented the accident.

  1. もう少し注意していれば、その事故は防げただろう。
  2. その事故のあと、人々はもう少し注意するようになった。
  3. もう少し注意しても、その事故は防げなかっただろう。
  4. その事故を防ぐには、さらに多くの注意が必要になるだろう。
正解と解説を見る

正解：1. もう少し注意していれば、その事故は防げただろう。

もう少し注意していれば、その事故は防げただろう。

主語 A little more care に「もう少し注意していれば」という仮定が含まれている。would have prevented は仮定法過去完了で、実際には事故は起きた。
