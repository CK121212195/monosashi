仮定法①（過去・過去完了・混合）

仮定法 高校文法

仮定法は「事実とは違う」ことを、時制を1つ過去にずらして表します。この「ずらし」が現実との距離を表します。

仮定法過去：今の事実と反対

If S＋過去形, S＋would / could / might＋原形。be動詞は主語にかかわらず were が正式（口語では was も）。

  • If I had more time, I would learn Spanish.
    もっと時間があれば、スペイン語を学ぶのに。実際は時間がない
  • If I were you, I would accept the offer.
    私があなたなら、その申し出を受けるだろう。

仮定法過去完了：過去の事実と反対

If S＋had＋過去分詞, S＋would / could / might＋have＋過去分詞。

  • If we had invested earlier, we would have made a profit.
    もっと早く投資していれば、利益が出ていただろう。実際は投資しなかった
  • If the bank had held fewer long-term bonds, it might have survived.
    長期債の保有が少なければ、その銀行は生き残れたかもしれない。

混合仮定法と未来の仮定

混合：過去の条件が今に影響する。If S＋had p.p., S＋would＋原形（now）。
If S should＋原形：万一～なら（主節は命令文や will も可）。
If S were to＋原形：仮に～すれば（実現性に関係なく仮定）。

  • If I had taken the job, I would be living in London now.
    あの仕事を受けていたら、今ごろロンドンに住んでいるだろう。混合
  • If you should have any questions, please contact us.
    万一ご質問があれば、ご連絡ください。
  • If prices were to double, many families would struggle.
    仮に物価が倍になれば、多くの家庭が苦しむだろう。

⚠️ 間違えやすいポイント

  • If 節に would を入れない（× If I would have time）。
  • 過去の仮定の主節は would have p.p.（× would ＋過去形）。
  • 混合仮定法：if 節は過去完了、主節は would＋原形（now などが手がかり）。

🎯 TOEIC・英検での出方

Part 5 で「If S had p.p. → would have p.p.」の対応、Part 6 / 7 で If you should ～ / Should you ～ の丁寧な表現が出ます。

演習問題（5問）

Q1 If the weather    better, we would hold the party outside.

  1. is
  2. were
  3. has been
  4. will be
正解と解説を見る

正解：2. were

天気がもっとよければ、パーティーを屋外で開くのに。

主節が would＋原形 なので仮定法過去。be動詞は were。

Q2 If we had known about the delay, we    another flight.

  1. would have booked
  2. would book
  3. will book
  4. had booked
正解と解説を見る

正解：1. would have booked

遅れを知っていたら、別の便を予約していただろう。

if 節が had known（仮定法過去完了）なので、主節は would have p.p.。

Q3 If she had accepted the offer, she    in New York now.

  1. would have worked
  2. will work
  3. had worked
  4. would be working
正解と解説を見る

正解：4. would be working

あの申し出を受けていたら、彼女は今ごろニューヨークで働いているだろう。

now があるので混合仮定法。過去の仮定→今の結果で would＋原形（進行形）。

Q4 If you    need further assistance, please call our help desk.

  1. should
  2. shall
  3. must
  4. would
正解と解説を見る

正解：1. should

万一さらにお手伝いが必要でしたら、ヘルプデスクにお電話ください。

If S should＋原形（万一～なら）。主節は命令文でも構いません。

Q5 If the company    more carefully, it would not have lost so much money.

  1. had planned
  2. would plan
  3. planned
  4. has planned
正解と解説を見る

正解：1. had planned

その会社がもっと慎重に計画していれば、あれほどの損失は出さなかっただろう。

主節が would not have lost（過去の事実と反対）なので、if 節は過去完了。
