否定語句が文頭に出ると倒置

Never / Rarely / Seldom / Hardly / Little / Not until ～ / Only＋副詞句 / Under no circumstances / Not only が文頭に来ると、疑問文と同じ語順（助動詞＋S＋V）になります。

  • Never have I seen such a beautiful painting.
    これほど美しい絵を見たことがない。
  • Only after the meeting did I realize the mistake.
    会議が終わってから初めて誤りに気づいた。
  • Under no circumstances should you share your password.
    どんな場合でもパスワードを共有してはいけない。
  • Little did he know that the company would soon collapse.
    その会社がまもなく破綻するとは彼は夢にも思わなかった。

So / Neither と、補語・場所句の倒置

So＋V＋S（Sもそうだ）、Neither / Nor＋V＋S（Sもそうではない）。
補語や場所の句が文頭に来ると S と V が入れ替わることがあります：Enclosed is a copy of the invoice.（請求書の写しを同封します）／On the hill stands an old castle.

  • She likes jazz, and so do I.
    彼女はジャズが好きで、私もそうだ。
  • Attached is the revised schedule.
    修正した予定表を添付します。補語の倒置

強調・省略・同格

強調：do / does / did＋原形（本当に～する）、the very＋名詞（まさにその）、ever / on earth / in the world（疑問詞の強調）。
省略：副詞節で主語と be動詞を省く（while (I was) in Tokyo, if (it is) necessary, when (it is) completed）、if any / if ever（たとえあるとしても）。
同格：名詞＋, 名詞（説明を並べる）、名詞＋that 節（the fact that ～）。

  • I did send the email yesterday.
    昨日、確かにメールを送りました。強調の did
  • If necessary, we will extend the deadline.
    必要なら締め切りを延ばします。省略
  • There are few, if any, mistakes in the report.
    その報告書には誤りはほとんどない（あるとしてもごくわずか）。
  • Mr. Tanaka, the new director, will speak first.
    新任の部長である田中氏が最初に話す。同格

⚠️ 間違えやすいポイント

  • 否定語句が文頭なら助動詞を主語の前に（× Never I have seen）。
  • Only＋副詞句が文頭でも倒置（Only then did I ～）。
  • Enclosed / Attached is ～ は S と V の一致に注意（Attached are the files）。

🎯 TOEIC・英検での出方

Part 5 で「Rarely / Seldom / Only when で始まる倒置」「Attached / Enclosed is / are」、Part 7 で強調や挿入の読み取りが出ます。

演習問題（5問）

Q1 Rarely    such strong demand for a new product.

  1. have we seen
  2. we saw
  3. we have seen
  4. saw we
正解と解説を見る

正解：1. have we seen

新製品にこれほど強い需要があるのはめったに見たことがない。

否定語 Rarely が文頭なので倒置（助動詞 have＋主語 we＋seen）。

Q2 Enclosed    a copy of the signed contract.

  1. being
  2. are
  3. is
  4. be
正解と解説を見る

正解：3. is

署名済みの契約書の写しを同封いたします。

補語 Enclosed が文頭に出た倒置。主語は a copy（単数）なので is。

Q3 Not until the data was reviewed    the error.

  1. did we notice
  2. we did notice
  3. noticed we
  4. we noticed
正解と解説を見る

正解：1. did we notice

データを見直して初めて、私たちは誤りに気づいた。

Not until ～ が文頭なので主節が倒置（did＋S＋原形）。

Q4 The manager didn't approve the plan, and    did the director.

  1. either
  2. so
  3. nor either
  4. neither
正解と解説を見る

正解：4. neither

部長はその計画を承認せず、取締役もしなかった。

否定文を受けて「～もそうではない」は neither＋V＋S。

Q5 Please contact the IT department    necessary.

  1. unless
  2. whether
  3. if
  4. despite
正解と解説を見る

正解：3. if

必要であればIT部門に連絡してください。

if (it is) necessary の省略形。
