that と as の識別

難関大・東大：構文を読む 難関大・東大

that と as は、1語で何役もこなす語です。読解でも和訳でも、まず「この that / as は何か」を決めることが正確な理解の出発点になります。

📗 先に確認したい基礎：関係代名詞、接続詞（と前置詞との区別）

that の5つの働き

① 関係代名詞：後ろが不完全な文（主語か目的語が欠けている）。the book that I read
② 名詞節を作る接続詞：後ろが完全な文。「～ということ」。I know that he is right.
③ 同格の that：the fact / idea / news / possibility / belief ＋ that ＋完全な文。「～という…」
④ 強調構文：It is ～ that …
⑤ 副詞節の一部：so ～ that / such ～ that（とても～なので）、so that（～するために）、now that（今や～なので）、in that（～という点で）

  • The fact that he had no experience did not stop him.
    経験がないという事実も、彼を止めなかった。同格の that：後ろは完全な文
  • The fact that he mentioned in his speech surprised everyone.
    彼が演説で触れたその事実は、皆を驚かせた。関係代名詞：mentioned の目的語が欠けている
  • Humans differ from other animals in that they use complex language.
    人間は、複雑な言語を使うという点でほかの動物と異なる。in that ～：～という点で

as の主な働き

接続詞：時（～するとき・～しながら）、理由（～なので）、様態（～のように）、比例（～するにつれて）、譲歩（形容詞＋as S V：～だけれども）。
前置詞：～として（as a teacher）。
関係代名詞のような働き：such ～ as、the same ～ as、文全体を受ける as。
見分け方：後ろが名詞だけなら前置詞、S＋V があれば接続詞。接続詞の場合は、主節との関係から意味を決めます。

  • As we get older, we tend to become more cautious.
    年をとるにつれて、私たちは慎重になりがちだ。比例：get older と become more cautious が連動
  • Young as he was, he was given a position of great responsibility.
    若かったけれども、彼は大きな責任のある地位を与えられた。譲歩：形容詞＋as S V
  • Leave things as they are until the police arrive.
    警察が来るまで、物はそのままにしておきなさい。様態：そのままの状態で

so that と、so ～ that・such ～ that

so that S can / will ～：～するために（目的）。, so that ～（カンマあり）：その結果～。
so＋形容詞・副詞＋that／such (a)＋形容詞＋名詞＋that：とても～なので…。
so＋形容詞＋a＋名詞の語順（so difficult a problem）にも注意します。

  • She spoke slowly so that everyone could follow her.
    全員がついてこられるように、彼女はゆっくり話した。目的
  • It was such a difficult problem that no one could solve it.
    それはとても難しい問題だったので、だれも解けなかった。such a＋形容詞＋名詞＋that

⚠️ 間違えやすいポイント

  • 同格の that と関係代名詞の that は、後ろが完全な文かどうかで見分ける。
  • 形容詞＋as S V（Young as he was）は「理由」ではなく「譲歩」で訳すのが基本（文脈によっては理由の意味になることもある）。
  • so that は目的、such ～ that は結果・程度。訳し分けを混同しない。

🎯 入試（難関大・東大）での出方

難関大の和訳問題では、同格の that や in that、譲歩の as などの識別が採点のポイントになります。誤り指摘問題では、関係代名詞と接続詞の取り違え（後ろが完全な文かどうか）がよく狙われます。

演習問題（6問）

Q1 There is growing evidence    regular exercise improves memory.

  1. which
  2. as
  3. that
  4. what
正解と解説を見る

正解：3. that

定期的な運動が記憶力を高めるという証拠が増えている。

後ろが完全な文なので同格の that（evidence の内容を説明する）。which / what の後ろは不完全な文になる。

Q2 Tired    she was, she kept working until midnight.

  1. so
  2. since
  3. as
  4. because
正解と解説を見る

正解：3. as

疲れていたけれども、彼女は真夜中まで働き続けた。

形容詞＋as S V で「～だけれども」（譲歩）。

Q3 Language is unique    it allows us to talk about things that do not exist.

  1. now that
  2. such that
  3. so that
  4. in that
正解と解説を見る

正解：4. in that

言語は、存在しないものについて語ることを可能にするという点で独特だ。

in that ～（～という点で）。so that は目的・結果、now that は「今や～なので」。

Q4 It was    that we decided to have lunch in the park.

  1. so a beautiful day
  2. such a beautiful day
  3. such beautiful a day
  4. so beautiful day
正解と解説を見る

正解：2. such a beautiful day

とても天気のよい日だったので、私たちは公園で昼食をとることにした。

such a＋形容詞＋名詞＋that。so を使うなら so beautiful a day の語順になる。

英文の意味として最も適切なものを選ぶ

Q5 As the population ages, the demand for medical care will continue to rise.

  1. 人口が高齢化するにつれて、医療の需要は増え続けるだろう。
  2. 人口が高齢化しているので、医療の需要はもう増えないだろう。
  3. 人口の高齢化と同じように、医療の需要も増え続けてきた。
  4. 人口が高齢化しても、医療の需要は増え続けるとは限らない。
正解と解説を見る

正解：1. 人口が高齢化するにつれて、医療の需要は増え続けるだろう。

人口が高齢化するにつれて、医療の需要は増え続けるだろう。

As S V は、変化を表す動詞（age・grow・increase など）と組むと「～するにつれて」（比例）の意味になりやすい。主節の continue to rise と連動している点に注目。

誤りを含む下線部を選ぶ

Q6 The idea which everyone should learn a foreign language has become widely accepted in recent years.

  1. has become
  2. The idea which
  3. should learn
  4. in recent years
正解と解説を見る

正解：2. The idea which

正しい文：The idea that everyone should learn a foreign language has become widely accepted in recent years.

だれもが外国語を学ぶべきだという考えは、近年広く受け入れられるようになった。

which の後ろが完全な文（everyone should learn a foreign language）なので、関係代名詞ではなく同格の that が必要。
