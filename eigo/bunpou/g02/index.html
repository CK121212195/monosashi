現在・過去・未来と進行形

時制 高校文法

現在形は「いつもそう」

現在形は、習慣・事実・不変の真理を表します。また、時刻表や公式の予定のように確定した未来にも使います。

  • The market opens at nine.
    市場は9時に開く。習慣・予定
  • The train leaves at 7:15 tomorrow.
    電車は明日7時15分に出る。確定した予定

時・条件を表す副詞節では、未来でも現在形

when, before, after, until, as soon as, once, if, unless などが作る副詞節では、未来のことでも現在形（または現在完了）を使います。TOEIC の最頻出ポイントの1つです。
ただし、「いつ～か」「～かどうか」を表す名詞節（know の目的語など）では will を使います。

  • We will start the meeting when the manager arrives.
    部長が着いたら会議を始めます。× when the manager will arrive
  • If it rains tomorrow, the event will be held indoors.
    明日雨なら、行事は屋内で行われる。条件節は現在形
  • I don't know when he will arrive.
    彼がいつ着くのかわからない。名詞節なので will

進行形と状態動詞

進行形は「一時的に進行中・途中」を表します。状態動詞（know, believe, belong, own, contain, consist, resemble, need, prefer など）は原則として進行形にしません。
未来の進行形 will be ～ing は「（自然な流れで）～していることになる」という予定を表します。

  • The company is developing a new chip.
    その会社は新しいチップを開発中だ。進行中
  • This box contains fragile items.
    この箱には壊れやすい品物が入っている。× is containing
  • We will be launching the product next month.
    来月その製品を発売する予定です。未来進行形

⚠️ 間違えやすいポイント

  • when / if / until / as soon as の副詞節に will を入れない。
  • know, own, belong, contain を進行形にしない。
  • 「～に属している」は belong to（× am belonging）。

🎯 TOEIC・英検での出方

Part 5 で「by the time / as soon as / once の後の時制」「文末の時の表現（next month, last year, since 2020）」から時制を決める問題が毎回のように出ます。

演習問題（5問）

Q1 Please call me as soon as the shipment   .

  1. would arrive
  2. will arrive
  3. arrives
  4. arrived
正解と解説を見る

正解：3. arrives

荷物が届いたらすぐに電話してください。

as soon as は時の副詞節。未来のことでも現在形 arrives を使います。

Q2 The seminar    at 10 a.m. every Monday.

  1. is beginning
  2. begins
  3. has begun
  4. began
正解と解説を見る

正解：2. begins

そのセミナーは毎週月曜の午前10時に始まる。

every Monday（毎週月曜）は習慣なので現在形。

Q3 Nobody knows when the new store   .

  1. opens
  2. opened
  3. has opened
  4. will open
正解と解説を見る

正解：4. will open

新しい店がいつ開店するのか誰も知らない。

when 以下は knows の目的語になる名詞節なので、未来は will で表します。副詞節と区別できるかがポイント。

Q4 This package    several fragile items.

  1. are containing
  2. contain
  3. contains
  4. is containing
正解と解説を見る

正解：3. contains

この荷物には壊れやすい品物がいくつか入っている。

contain は状態動詞なので進行形にしません。主語は単数なので contains。

Q5 Unless sales    next quarter, the project will be canceled.

  1. improving
  2. improve
  3. will improve
  4. improved
正解と解説を見る

正解：2. improve

来四半期に売上が改善しなければ、その計画は中止される。

unless（～しない限り）は条件の副詞節。未来でも現在形 improve。
