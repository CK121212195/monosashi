発音と表示の設定

発音のアクセント
文を読み上げる速さ（合成音声）

発音について：単語の🔊は、Wiktionary に投稿された録音を Free Dictionary API 経由で取得して再生します（録音は各投稿者によるもので、主に CC BY-SA ライセンスです）。録音が見つからない語、熟語、文は、お使いの端末の合成音声で読み上げます。再生のたびに「録音」か「合成音声」かを表示します。

合成音声は自然さが端末によって大きく異なり、まれに強勢の位置を誤ることがあります。発音記号（IPA）とあわせて確認してください。

英語のものさし は 数字のものさし の無料ツールです。問題・本文はすべて当サイトのオリジナルで、英検・TOEICの公式問題ではありません。「英検」は公益財団法人 日本英語検定協会の、「TOEIC」は ETS の登録商標です。

学習記録と単語帳は、お使いのブラウザ（localStorage）にのみ保存され、外部へは送信されません。発音の録音を取得するときだけ、調べた単語が Free Dictionary API に送られます。
